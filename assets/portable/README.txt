LiMusic Forge - portable mode
=============================

This "data" folder, next to limusic-forge.exe, turns on portable mode.
Everything the app keeps (settings, library, accounts and sign-in session,
webview profile, logs) is stored here and nowhere else on the PC.

- To move or back up the app, move or copy the whole folder: the exe,
  libmpv-2.dll and this data folder together.
- Portable copies do not update themselves. To update, download the new
  limusic-forge_<version>_x64-portable.zip from the GitHub releases page and
  extract it over the app folder (this data folder is kept).
- Requires the Microsoft Edge WebView2 Runtime installed on the system
  (included with Windows 11 and current Windows 10).
- It shares a single instance with an installed LiMusic Forge: only one of
  the two can run at a time.
- Delete the contents of this data folder only if you want to start from scratch.


LiMusic Forge - modo portable
=============================

Esta carpeta "data", junto a limusic-forge.exe, activa el modo portable.
Todo lo que guarda la app (ajustes, biblioteca, cuentas y sesión iniciada,
perfil del webview, registros) queda aquí y en ningún otro lugar del equipo.

- Para mover o respaldar la app, mueve o copia la carpeta completa: el exe,
  libmpv-2.dll y esta carpeta data juntos.
- La copia portable no se actualiza sola. Para actualizar, descarga el nuevo
  limusic-forge_<version>_x64-portable.zip desde la página de releases de
  GitHub y extráelo sobre la carpeta de la app (esta carpeta data se conserva).
- Requiere el Microsoft Edge WebView2 Runtime instalado en el sistema
  (viene con Windows 11 y con Windows 10 actualizado).
- Comparte instancia única con LiMusic Forge instalado: sólo una de las dos
  puede estar abierta a la vez.
- Borra el contenido de esta carpeta data sólo si quieres empezar de cero.
